Sizing on a napkin

Will an 8B model fit in 24 GB?

1 · Model weights8 billion parameters × 2 bytes (16-bit) = ≈ 16 GB
2 · Memory per token (KV cache)2 × 32 layers × 8 heads × 128 × 2 bytes = 128 KB
→ one 8,000-token conversation ≈ 1 GB
3 · What's left21.6 GB usable − 16 GB weights − 1.5 GB overhead ≈ 4 GB
→ about 4 long conversations at once, many more short ones

AI terms, in plain English · 1 of 4

The basics

AaLLM

Large Language Model. An AI trained on huge amounts of text to predict the next word. ChatGPT and Llama are LLMs.

Today: Llama 3.1 8B Instruct

#Parameters

The numbers a model learned during training: its "knowledge". "8B" means 8 billion of them. More usually means smarter, but bigger.

Today: 8 billion × 2 bytes ≈ 16 GB

GGPU

A chip with thousands of small cores that do math in parallel. AI models are mostly huge multiplications, so GPUs run them far faster than CPUs.

Today: NVIDIA L4

MVRAM

The GPU's own built-in memory. The whole model has to fit here to run fast, which is why GPU memory size matters so much.

Today: 24 GB

AI terms, in plain English · 2 of 4

Running a model

▶Inference

Using a trained model to answer a question. Training teaches the model; inference is the model doing its job. This video is all inference.

Today: serving answers through an API

TToken

A chunk of text, roughly three-quarters of a word. Models read and write tokens, and speed and price are measured in them.

Today: we count tokens per second

⟷Context window

How much text the model can look at in one go, your prompt plus its answer, measured in tokens.

Today: we cap it at 8,000 tokens

KKV cache

The model's short-term memory for each conversation, so it doesn't re-read everything for every new word. It lives in VRAM and grows as the chat gets longer.

Today: ≈ 128 KB per token

AI terms, in plain English · 3 of 4

Making it fast and cheap

vvLLM

Free, open-source software that serves LLMs. It packs many users' requests onto one GPU efficiently and speaks the same API format as OpenAI.

Today: our model server

4Quantization

Storing each parameter with fewer bits, for example 4 instead of 16. The model gets about 4× smaller and faster, with a small loss in quality.

Today: 16-bit vs. 4-bit (AWQ)

⏱Throughput vs. latency

Throughput: total words per second across all users. Latency: how long one person waits. Serving more users at once raises throughput but adds some wait.

Today: we measure both

$On-demand vs. Spot

On-demand: pay by the second, never interrupted. Spot: AWS's spare capacity, often 50 to 70% cheaper, but it can be taken back with 2 minutes' notice.

Today: on-demand, for a stable recording

Cloud terms, in plain English · 4 of 4

The cloud pieces

EEC2 instance type

A rented virtual machine in a preset size. The name tells you the family and size: "g6" is AWS's GPU family, "xlarge" the size.

Today: g6.xlarge = 4 vCPU, 16 GB RAM, 1 L4

ADeep Learning AMI

A ready-made machine image from AWS with NVIDIA drivers, CUDA and Docker already installed, so you skip hours of setup.

Today: our starting image

DEBS volume

A network-attached disk for your virtual machine. It keeps files like downloaded model weights between restarts.

Today: 100 GB gp3

QService quota

AWS's per-account safety limit. New accounts often start at zero GPU capacity, so you ask AWS for an increase before you can launch.

Today: "Running On-Demand G and VT instances"
